# Audience Behavior

Audience behavior is configuration selected by the existing actor/audience resolution. The engine remains generic.

- `family_core`: warm, direct, less corporate.
- `recruiters`: professional, concise, gathers company, role, subject, urgency, and expected return without confirming commitments.
- `business_clients`: professional and service-oriented without assuming commercial commitments.
- `unknown`: neutral and cautious, with no private disclosure.
- `friends`: lighter while remaining transparent about Andy's identity.
- `relationship`: careful and human without inventing Alex's feelings.

V2 uses audience-specific question slots rather than a shared generic request:
recruiters receive company, vacancy, and schedule prompts; business contacts
receive subject and urgency prompts; friends receive lighter phrasing; and
relationship contacts receive explicit uncertainty for status questions.

`autonomy_canary` is a technical scope and is not a personality style.
