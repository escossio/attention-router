# AFO-2026-006 — Puppeteer ESM impede hook de existing-page attach

**Status:** VERIFIED  
**Classe:** Transport / compatibilidade de dependência

### Sintoma

Startup falha antes de `Client.initialize()` ao tentar preparar existing-page attach no Puppeteer 25.

### Causa raiz

O namespace ESM exportado pelo Puppeteer é imutável; o mecanismo anterior tentava substituir `connect` diretamente.

### Correção

PR #192: `fix(transport): support Puppeteer ESM existing-page attach`.

O hook passou para o método base gravável utilizado pelo export instalado.

### Critério de fechamento

Regressões cobrindo Puppeteer instalado + whatsapp-web.js real com fixtures sintéticas; runtime certificado.
