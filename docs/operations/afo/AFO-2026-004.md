# AFO-2026-004 — Reconstrução perde paridade de configuração efetiva do Worker

**Status:** ROOT_CAUSE_PROVEN  
**Classe:** configuration drift / reproducibilidade

### Sintoma atual crítico

Mensagens direct chegam a `AUTO_ALLOWED`, criam ExecutionIntent `RELEASED`, mas terminam:

`BLOCKED: AGENT_EXECUTION_DISABLED`

### Evidência

Comparação do `docker inspect` do último Worker funcional com o Worker atual.

Diferenças relevantes:

- `AGENT_EXECUTION_ENABLED`: `true` -> `false`
- `AGENT_DECISION_DEFAULT_BLUEPRINT_ID`: presente -> ausente
- `OWNER_CONTROL_SEMANTIC_ENABLED`: `true` -> ausente
- `OWNER_CONTROL_SEMANTIC_MODEL`: presente -> ausente
- `STT_ENABLED`: `true` -> `false`
- `WHATSAPP_MEDIA_ROOT`: presente -> ausente
- redes: bridge/default + TTS + VLAN -> apenas VLAN 213
- DB/Transport/TTS/STT endpoints mudaram legitimamente para endereços das VLANs
- imagem/build mudou de `6611eac1` para `b3a0c302`

O Worker funcional foi materializado a partir de 12 Compose files sobrepostos. O Worker reconstruído usa uma configuração mínima independente.

### Causa raiz

Não existia uma representação canônica/materializada da configuração efetiva do Worker. O estado de produção dependia de uma pilha histórica de overlays. A reconstrução de topologia recriou o processo, mas não recriou integralmente sua semântica operacional.

### Impacto

O componente aparece saudável em Docker e rede, mas possui comportamento diferente do último runtime funcional.

### Observação crítica

Nem toda configuração antiga deve ser restaurada cegamente. O antigo `AGENT_DECISION_DEFAULT_BLUEPRINT_ID` aponta para o `Autonomy Canary`, relacionado à AFO-2026-008.

Portanto a remediação exige classificação de cada diferença:

- preservar semanticamente;
- substituída legitimamente pela VLAN;
- obsoleta deliberadamente;
- artefato de canário;
- perdida acidentalmente.

### Observabilidade obrigatória para fechamento

- fingerprint da configuração efetiva;
- lista de Compose/config sources;
- image/build SHA;
- restart policy;
- redes anexadas;
- gates críticos materializados no painel;
- diff automático contra baseline aprovado.

### Teste de regressão necessário

Recriação do Worker do zero a partir de artefato declarativo único deve produzir o mesmo fingerprint sem depender de arquivos temporários ou sequência histórica de overlays.

### Critério de fechamento

Runtime reconstruível + canário físico E2E PASS.
