# Changelog

All notable changes to this project are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project follows [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-09-09

Public prerelease of the sanitized Attention Router baseline.

### Added

- Provider-free local Quick Start for the core API and PostgreSQL.
- Contribution, security, issue-reporting, and pull-request workflows.
- Structured inbound processing, policy and approval boundaries, transactional outbox, delivery evidence, optional voice adapters, and the local WhatsApp transport test suite.

### Security

- Hardened WhatsApp Web navigation trust validation using exact URL origin checks and adversarial regression tests.
